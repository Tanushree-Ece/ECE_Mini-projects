# Analog IC Design Mini Projects

## Overview

This repository contains a collection of mini projects in Analog IC Design developed using Cadence Virtuoso. The projects focus on understanding fundamental analog circuits, CMOS design techniques, and low-power circuit design.

## Topics Covered

* Operational Amplifiers
* Differential Amplifiers
* Current Mirrors
* Biasing Circuits
* Low-Power Design Techniques

## Tools Used

* Cadence Virtuoso
* Spectre Simulator

## Purpose

The goal of these projects is to gain hands-on experience in transistor-level circuit design, simulation, and analysis while building a strong foundation in analog integrated circuits.

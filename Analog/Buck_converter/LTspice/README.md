# LTspice Folder

The **LTspice** folder contains the source files required to reproduce the simulation.

### Contents

| File | Description |
|------|-------------|
| **buck_converter.asc** | LTspice schematic file containing the complete circuit |
| **buck_converter.net** | Generated SPICE netlist of the converter |

These files can be opened directly in LTspice for further simulation or modification.

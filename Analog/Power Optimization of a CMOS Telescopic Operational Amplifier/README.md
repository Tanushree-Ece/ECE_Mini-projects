# Low-Power Telescopic Op-Amp Optimization

## Overview

This project focuses on reducing the power consumption of a CMOS telescopic operational amplifier. A benchmark telescopic op-amp design from an IEEE paper was implemented and modified using various low-power design techniques.

The performance of the optimized designs was compared against the original benchmark circuit to evaluate power reduction.

## Techniques Implemented

* Header Switch Technique
* Footer Switch Technique
* High Threshold Voltage (HVT) Devices
* Combination of Header, Footer, and HVT Techniques

## Tools Used

* Cadence Virtuoso
* Spectre Simulator

## Methodology

1. Implemented the benchmark telescopic op-amp from the reference paper.
2. Applied individual power optimization techniques.
3. Simulated each modified design.
4. Compared power consumption with the original circuit.

## Results

The optimized designs demonstrated reduced power consumption compared to the benchmark design, with the combined approach providing the highest reduction.

## Key Learnings

* Low-power analog design techniques
* Power-performance trade-offs
* CMOS transistor optimization
* Analog circuit simulation using Cadence Virtuoso
